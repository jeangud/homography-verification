# Contribution Guidelines
- For code modifications, install the package in editable mode: `pip install -e .[dev]`
- Install the pre-commit hook: `pre-commit install`
- For code formatting, linting, and testing, please directly see the steps in our automated [CI/CD job file](./workflows/build-and-test.yml).
- Most of our code tooling options are described in the [pyproject.toml](./pyproject.toml).
